Alexander Storage

Production-ready, S3-compatible object storage written in Go.

Deploy metadata on PostgreSQL or embedded SQLite, store blobs on local disk or S3, and scale across nodes with gRPC clustering.

Quick Start

Run with Docker in one command:

docker run -d \
  --name alexander \
  -p 8080:8080 \
  -p 9091:9091 \
  -v alexander_data:/var/lib/alexander \
  -e ALEXANDER_AUTH_MASTER_KEY=$(openssl rand -hex 32) \
  ghcr.io/neuralforgeone/alexander-storage:latest

Or build from source:

go build -o alexander-server ./cmd/alexander-server
./alexander-server --init-config
./alexander-server --config config.yaml

Architecture Highlights

  • S3 API compatibility — works with aws-cli, boto3, and Terraform
  • Content-addressable storage — SHA-256 deduplication
  • Multiple backends — filesystem (default) and s3
  • Cluster support — gRPC inter-node blob transfer and replication
  • Flexible metadata — PostgreSQL for production, SQLite for embedded/homelab
  • AWS Signature V4 — authentication and presigned URLs

CLI Tools

  • alexander-server — S3-compatible HTTP API server
  • alexander-admin — user and access key management
  • alexander-migrate — database migrations (up, down, status, create, force, version)
